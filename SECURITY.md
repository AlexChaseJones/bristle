# Security reports

Please report suspected Bristle vulnerabilities privately to **alexchasejones@icloud.com**, with “Bristle security” in the subject.

Include the affected version, impact, and minimal safe reproduction steps. Do not include live credentials or customer data. Do not publish exploit details in an issue before contacting the maintainer. There is no response SLA or bug-bounty program.

The current public beta is 0.1.11 Beta 1. Security updates, if needed, are distributed as new manual downloads. Review [release status](https://bristlebristle.app/releases/) and the attached IT packet before evaluation.
